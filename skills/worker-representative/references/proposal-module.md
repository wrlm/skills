# 内置模块：职代会提案辅导、撰写、优化与质量预审

本模块包含先前独立 proposal-advisor 的核心功能，不另设外部依赖。

## 模式
1. **选题**：检查群众基础、职代会职权、一事一案、现实意义、历史提案重复风险；给出1—3个可选具体题目。
2. **撰写**：输出题目、类别、案由和问题、原因分析、对策建议、承办单位建议、预期效果及待核实材料。
3. **优化**：保留核心诉求，对照证据与实施条件指出问题，提供完整修订稿及关键改动。
4. **预审**：先检查硬性风险，再评分，给出“建议提交 / 修改后提交 / 补充调研 / 建议转其他渠道”等非正式辅助意见。
5. **研讨发言**：按2—3分钟形成朴实的口语稿，拒绝捏造调研结果。

## 关键检查
- 主体：提案人是否为符合要求的职工代表；附议人是否知情且符合本单位要求。
- 代表性：职工群众实际诉求而非个人想象。
- 职责：是否属于职代会提案适宜范围；个人申诉应考虑其他渠道。
- 一事一案：一个主要问题和清晰承办方向。
- 事实：来源、数量、统计口径、已核实与待核实分开。
- 原因：客观深刻，不能把可能性当作确定结论。
- 措施：责任、动作、步骤、实施资源、成本、评价方式。
- 格式：名称简洁明确，依单位正式表格优先。
- 重复：已有决策或办结事项，宜聚焦执行优化而非照搬提案。

## 内部辅助评分（不是正式立案标准）
| 维度 | 分值 |
|---|---:|
| 选题质量 | 20 |
| 调查研究 | 25 |
| 案由分析 | 20 |
| 对策建议 | 25 |
| 格式规范 | 10 |

85—100为优质草稿；70—84建议修改；低于70建议重点辅导。**总分不能抵消硬性风险**，不存在事实依据不应给调查项满分。不得把评分等同立案决定。

## 输出格式
**提案名称**；**提案类别**；**案由及问题**；**原因分析**；**对策建议**；**建议承办单位（待核实）**；**预期效果及评价**；**提交前待核实项**。

## 典型风险
“广大职工普遍反映”没有样本；以口号替代选题；一份提案同时谈食堂、停车与报销；让无明确资金来源的部门承诺投资；让未经授权的单位承担责任；提案涉及个人责任追究；套用历史培训中的法规而未核对现行文本。
