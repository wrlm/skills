# 诉求、沟通、协商与反馈

## 四种素养
- **立场**：替谁说话？征求过哪些人的意见？
- **事实**：有没有记录、数据、规定、可核实的具体案例？
- **表达**：结论先行，结构清楚，控制发言时长。
- **边界**：能承诺到哪一步？哪些信息需要保密，哪些决定不在代表权限内？

## 把抱怨转为可处理事项
“感受 → 事实 → 影响 → 方案”。例如“班车太差”应进一步问是哪条线、几次晚点、影响多少人、期望何种调整；没有调查不得写成已确认事实。

## 分层访谈
- **一线职工**：先倾听，使用具体问题，解释保密和处理边界，不轻易说“保证解决”。
- **班组长**：同时询问班组工作约束、影响范围和可执行的改善办法。
- **中层管理者**：提前发送议题与事实材料，确认制度、预算、人力等约束。
- **高层管理者**：一页纸汇报，按“问题—证据—影响—建议—需要决策”组织。

## 协商准备
- 事实：时间、人数、数据来源、正反案例。
- 依据：适用法律制度、合同、已发布政策；核实原文。
- 方案：首选、备选及各自成本、可行条件。
- 边界：清楚自己能代表谁、能承诺什么、需哪些批准。

协商时先找共同目标，用证据替代形容词，追问不同意的具体约束，避免人身指责，形成可追踪记录。

## 投诉与矛盾
1. 受理：记录事项、诉求、时间和证据，保护隐私。
2. 分类：咨询、权益争议、人际矛盾、管理争议等。
3. 核实：听取有关方面意见，检查制度和事实。
4. 分流处理：能协调的推动协调；涉法律或重大事项转交有权限部门。
5. 回访：反馈已处理、办理中、无法处理的原因与下一步。

涉及严重骚扰、威胁、人身伤害等，不自行“调停”替代正式报告或保护程序。

## 三类常用表达
- **反映问题**：现状＋影响＋建议。
- **回应质询**：确认＋依据＋结论。
- **转达意见**：来源＋数量＋代表性（数字必须真实）。

每次发言前检查：代表谁、凭什么、说清楚了吗、权限到哪。
