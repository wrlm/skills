# 职工代表履职助手 / worker-representative

面向职工代表和工会工作者的中文 AI Skill。**一个 Skill 覆盖全部履职场景，内置原 proposal-advisor 的提案辅导与质量预审能力。**

## 能做什么

- 制度、权责与议题范围辅助查询
- 职工诉求访谈、事实核实及诉求台账
- 分层沟通、协商准备、投诉转办与回访
- 职代会审议、发言及代表述职
- 提案选题、撰写、优化、质量评分、2—3分钟发言
- 使用 `evals/proposal-cases.jsonl` 检查常见提案问题

## 安装

将 `skills/worker-representative` 复制到使用者的 Skills 目录；具体配置以该 AI 工具文档为准。

## 例句

- “有职工反映排班不公平，帮我做一份访谈提纲和事实核实清单。”
- “我下周参加职代会，帮我看这份议案该重点审查什么。”
- “把这个问题整理为职代会提案，严格遵守一事一案。”
- “帮我审查提案，重点找出事实不足和不可执行的措施。”
- “我准备与管理层谈福利调整，列出双方可能关切和备选方案。”

## 安全与适用性

本项目提炼的是通用工作方法，不包含培训原音、逐字稿及企业内部材料。课堂转写或讲师案例可能有识别错误或历史口径，具体法律政策须独立核验。AI不承担正式审批、仲裁、立案或决策职责。
