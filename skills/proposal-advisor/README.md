# proposal-advisor

**职代会提案辅导与质量审查 Skill** — 中文优先的开源 AI Skill。

帮助职工代表把真实诉求转化为具体、可核查、可落实的提案。支持提案选题、调研辅导、起草、优化、质量预审及2—3分钟发言稿。

## 功能
- **选题辅导**：代表性、一事一案、适用范围及证据缺口
- **撰写优化**：标题、案由、原因分析、对策措施及承办建议
- **质量预审**：非官方100分辅助评分、硬性风险、修改意见
- **准备研讨**：访谈提纲、发言稿及待核实清单
- **评测样例**：`evals/cases.jsonl`，8个虚构情境案例

## 安装
将此目录复制到所使用的 AI Agent 的 Skills 目录，确保 `SKILL.md` 位于 Skill 文件夹根部。具体加载方式因工具而异。

仓库地址：https://github.com/wrlm/skills

## 使用示例
- “想提一个关于AI岗位应用培训的提案，帮我先定选题和调研内容。”
- “请审查这份职代会提案，标出没有证据的断言。”
- “根据职工访谈优化案由，建议写出责任部门和实施步骤。”
- “把提案改成2—3分钟研讨发言稿。”

## 使用边界
- AI不是正式职代会审查机构，不保证立案。
- 不虚构调研、政策、预算、承办单位或成效。
- 上传职工或企业资料前，应自行脱敏，并遵守所在单位信息安全政策。
- 本地提案制度、征集通知和正式模板优先于通用指南。
